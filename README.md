# أتيليه نورث — Atelier North

صفحة هبوط لاستوديو عمارة: مشاريع مميزة مع بحث وتصفية، وخدمات تصميم، وفريق الاستوديو، وآراء تجريبية، ورسوم تصميم بعناصر نائبة `{{...}}`، وأسئلة شائعة، ونموذج بدء مشروع مع تحقق وحفظ في المتصفح.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
npm run preview
```

ثنائية اللغة (العربية RTL والإنجليزية LTR) مع زر تبديل وحفظ اللغة في `localStorage`. لا توجد متغيرات بيئة.
